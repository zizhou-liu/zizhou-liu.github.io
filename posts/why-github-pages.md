# 为什么选择 GitHub Pages 搭建个人博客

想搭一个个人博客，方案有很多，但 GitHub Pages 对独立开发者而言几乎是最省心的选择。

## 核心优势

| 优势 | 说明 |
| --- | --- |
| 免费托管 | 无需购买服务器，零成本起步 |
| 免备案 | 直接绑定 `username.github.io` 域名 |
| 版本可控 | 内容就是代码，天然支持 Git 版本管理 |
| 全球 CDN | GitHub 自带加速，访问稳定 |

## 我的选型思路

### 1. 静态优先

个人博客大多是**读多写少**的场景，完全没有必要上动态后端。静态站点加载快、安全、易维护。

### 2. 零依赖

这套博客刻意不引入框架，只用原生 HTML/CSS/JS，配合一个 `marked` 库渲染 Markdown。好处是：

- 学习成本低
- 构建简单
- 易于魔改

```html
<!-- 只需一行引入 Markdown 渲染库 -->
<script src="https://cdn.jsdelivr.net/npm/marked/marked.min.js"></script>
```

### 3. 内容即文件

每篇文章就是一个 `.md` 文件，写作时专注内容本身，不用关心页面结构。

## 部署步骤

1. 在 GitHub 新建仓库
2. 把站点文件推送到仓库
3. 在 Settings → Pages 中选择分支
4. 访问 `https://<用户名>.github.io/<仓库名>/` 即可

> 提示：如果你的仓库名是 `username.github.io`，则直接访问根域名即可。

简单、免费、可控，这就是我选择它的全部理由。
