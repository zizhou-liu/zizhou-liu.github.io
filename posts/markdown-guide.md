# Markdown 写作指南

Markdown 是一种轻量级标记语言，让你用纯文本写出格式化的文档。掌握常用语法，写作会更专注、更高效。

## 标题

使用 `#` 号表示标题层级：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 强调

- **加粗**：`**文字**`
- *斜体*：`*文字*`
- ~~删除线~~：`~~文字~~`
- `行内代码`：`` `代码` ``

## 列表

### 无序列表

- 项目一
- 项目二
  - 嵌套子项
- 项目三

### 有序列表

1. 第一步
2. 第二步
3. 第三步

## 引用

> 这是一段引用文字。
>
> 引用可以嵌套多行，用于强调或摘录。

## 代码块

用三个反引号包裹，并指定语言：

```python
def greet(name):
    return f"Hello, {name}!"
```

## 链接与图片

```markdown
[链接文字](https://example.com)

![图片描述](https://example.com/image.png)
```

## 表格

| 语法 | 效果 |
| --- | --- |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `` `代码` `` | `代码` |

## 分隔线

使用三个或更多的 `---`：

---

## 小结

掌握以上语法，你就已经能写出 90% 场景下需要的文档了。剩下的，交给内容和思考本身。
