# 响应式设计：让博客在手机上也好看

如今越来越多的人用手机阅读。一个博客如果只在桌面端好看，就失去了一半的读者。响应式设计，就是让页面在不同屏幕尺寸下都能优雅呈现。

## 核心原则

### 1. 移动优先

先为小屏幕设计，再逐步增强到大屏幕。这样能避免「桌面端塞得太满，移动端放不下」的尴尬。

### 2. 弹性布局

用相对单位（`%`、`rem`、`vw`）代替固定像素，让元素随容器伸缩。

```css
.container {
  width: 100%;
  max-width: 760px;
  margin: 0 auto;
  padding: 0 20px;
}
```

### 3. 媒体查询

在关键断点处调整布局：

```css
@media (max-width: 640px) {
  .site-nav {
    flex-direction: column;
  }
  .post-detail-header h1 {
    font-size: 1.7rem;
  }
}
```

## 常见断点

| 屏幕 | 宽度 | 策略 |
| --- | --- | --- |
| 手机 | < 640px | 单列、折叠导航 |
| 平板 | 640–1024px | 双列或宽单列 |
| 桌面 | > 1024px | 完整布局 |

## 图片自适应

让图片永远不超过容器宽度：

```css
img {
  max-width: 100%;
  height: auto;
}
```

## 触屏友好

移动端交互靠手指，点击目标要足够大：

- 按钮最小 `44px × 44px`
- 链接间距适当增加
- 支持 `:hover` 之外也要考虑触屏反馈

## 小结

响应式不是「做一个手机版」，而是让**同一份内容**在不同设备上自然流动。这个博客正是遵循了这些原则，欢迎你用手机打开试试。
